# StockGuard for YouTube — 크롬 익스텐션

불법 주식 리딩방 의심 유튜브 채널을 탐지해 경고·차단하는 확장. `notebooks/modeling.ipynb` 분석 결과를 제품으로 옮긴 설계([`DESIGN.md`](DESIGN.md))를 그대로 구현한 MVP.

## 설치 (개발자 모드)
1. Chrome → `chrome://extensions` → 우상단 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 `extension/` 폴더 선택
3. youtube.com에서 채널/영상 페이지 진입 시 동작

## 동작 원리 — 2단계 파이프라인 + 3층 규칙

```
채널/영상 페이지 → [Stage 0 도메인 게이트] 주식·경제 채널 아니면 판단 안 함
                        ↓
                 [Stage 1] 규제어 regex + RandomForest 의심 점수
                        ↓
              차단 / 경고 / 통과
```

| 층 | 조건 | 동작 |
|---|---|---|
| 차단 | 규제어 hit **그리고** 점수 ≥ 0.834 | 화면 가림 + 사유 표시 + 그래도 보기/허용 |
| 경고 | 점수 ≥ 0.658 | 배너 + 금감원 신고센터 링크 |
| 통과 | 그 외 | 표시 없음 |

- 모델 단독 차단 금지(H1 기각 결론) — 차단은 금융위 규제어라는 법적 근거 동반 시에만.
- threshold는 경량 모델(아래)의 테스트셋 precision-recall 운영점에서 산출: precision≥0.9 → 0.834(차단), precision≥0.7 → 0.658(경고). 노트북 full 모델의 0.92/0.77과 다른 이유 = feature 부분집합으로 재학습했기 때문.

## 경량 모델
페이지에서 즉시 파싱 가능한 feature 13개만으로 재학습한 RandomForest(100 trees, depth 8).

- 규모: log 구독자/영상수/총조회 + 영상 조회 중앙값
- 나이: 채널 나이, 신생(1년 미만) 플래그
- 형식: 채널 설명의 URL/카톡/전화/텔레그램/밴드/이메일 플래그 (규제어는 feature 아님 — leakage 차단)
- 기타: is_kr

테스트셋 AUC **0.767** (full 36개 feature 모델 0.80). 페이지에서 못 읽는 값(가입일·총조회 등)은 학습 중앙값으로 대치.

재학습·내보내기:
```bash
.venv/bin/python extension/train/train_lite.py   # → extension/model_data.js 갱신
```

## 파일 구조
| 파일 | 역할 |
|---|---|
| `manifest.json` | MV3 매니페스트 |
| `content.js` | 채널 식별 → HTML 파싱 → 게이트 → 판정 → 배너 |
| `reg.js` | 규제어 regex(금융위·금감원 근거) + Stage 0 게이트 키워드 |
| `model.js` | forest 평가기 |
| `model_data.js` | 직렬화 모델(자동 생성, 수정 금지) |
| `popup.*` | 활성화 토글 + 허용 채널 관리 |
| `train/train_lite.py` | 경량 모델 학습·내보내기 |

## 한계
- **YouTube 내부 구조 의존**: `ytInitialData` 문자열 패턴 파싱이라 유튜브 개편 시 깨질 수 있음. 파싱 실패 = 판단 보류(오탐 방지 우선).
- **한국어 UI 가정**: 구독자·조회수 파싱이 한국어 표기("1.42만명") 기준.
- **댓글 feature 부재**: 도배율(author_uniq)·시딩(med_ttf) 등 가장 차별적인 댓글 신호는 페이지에서 즉시 계산 불가 → 서버 배치 + API 수집이 후속 과제.
- **시드 라벨 한계**: 모델 라벨이 규제어 휴리스틱(골드라벨 아님). 점수는 의심 순위지 판별이 아님.
- **법적 고지**: 차단·경고는 분석 기반 의심 정보 제공일 뿐 법적 판단이 아님. 최종 판단·제재는 금융당국(금감원 fine.fss.or.kr) 몫.
